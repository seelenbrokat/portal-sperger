# Sperger Portal

Kopie des WOG-Portals (WOG-APP), umbenannt und als eigenständiges **Sperger Portal** bereitgestellt.

## Herkunft

Basis: [seelenbrokat/WOG-APP](https://github.com/seelenbrokat/WOG-APP)

## Branding

- Anzeigename: Sperger Portal
- Application ID: `com.sperger.portal`
- Projektname: `portal-sperger`

## Build

Android-Projekt (Gradle/Kotlin). Mit Android Studio öffnen oder:

```bash
./gradlew assembleDebug
```
